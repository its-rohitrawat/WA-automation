# Lane C plan: up to 5 WhatsApp phones (change 7)

> For agentic workers: build task by task, test first. Each task is: write its tests and see them fail, write the code,
> see them pass, mutation-check the guard, then commit. Ask the coordinator for a slot before every typecheck or test
> run (one run at a time across all lanes), and run with `--maxWorkers=2`. Never push, merge or deploy, and never read
> or print `.env`.

**Goal:** every workspace reads its groups through up to five linked phones. Phone 1 is today's phone, kept with no
relink.

**Architecture:** see docs/superpowers/specs/2026-11-02-nov-c-phones-design.md. In short:
- a `PhoneSet` that is the app's one gateway and routes by group;
- the phone list in kv `wa_phones`, and a group's phone in its approved-group entry;
- per-phone session names and subkeys;
- one Postgres change: P7 widens `wa_auth`'s phone check.

**Tech:** TypeScript on Node 24, vitest, Baileys, SQLite and Postgres (row security), and the dashboard's own front end.

Each task lands only when the coordinator has reviewed it. Loans are asked for just before the task that needs them.

### Task 5: the PhoneSet (src/wa/phoneSet.ts, new)

Tests first (tests/wa/phoneSet.test.ts, with fake gateways):
- Each phone's events reach `onEvent`. `setConfigs` splits the groups by phone, and a group's events come only from its
  phone. The same group on two phones is read once: the other phone drops it as not allowed.
- `groupSocket` and `fetchHistory` go to the group's phone only. They return null or false when that phone is closed,
  even if another phone is open.
- `status()`: open only when every active phone is open. Otherwise the worst state, naming the phone. Unlinked phones
  are not counted. `phones()` gives each phone's state.
- `listGroups()` unions the open phones' lists, with the phones that see each group.
- Adding a phone starts its gateway. Unlinking one stops only that phone's gateway. `stop()` stops all of them, each
  capped.
- `idle()` waits for every phone's queued events, as `SwitchableGateway.idle` does.

Commit: "feat(wa): PhoneSet, one gateway per phone behind the app's gateway".
