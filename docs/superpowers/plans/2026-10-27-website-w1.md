# Public website W1

> **For agentic workers:** use superpowers:subagent-driven-development or superpowers:executing-plans, task by task. This is a new project in `C:\Users\Dell\Desktop\wa-agent-website` (local `git init`; the private GitHub repo `wa-agent-website` is created only after the owner approves). Match `C:\Users\Dell\Desktop\wa-agent-mockups\pages\` (`site.html`, `demo.html`, `contact.html`, `privacy.html`, `terms.html`, `404.html`, `offline.html`); their build sources are in `..\source\`.

**Goal:** the public site at `waagent.agentsolutionbowl.si/`, rebuilt properly from the approved mockups as a static export for Cloudflare Pages. A small Cloudflare Worker sends `/dashboard*` to the agent's tunnel.

**Architecture:**
- Next.js (App Router) with `output: 'export'` and TypeScript. Each homepage section is its own component.
- GSAP ScrollTrigger runs the scroll scenes, in client components with cleanup on unmount (`gsap.context`).
- Three.js runs the hero core and the ending planet, in isolated client components that pause when off screen.
- No Framer Motion: don't mix it with GSAP.
- No data from the agent; all demo data is labelled.

**Tech stack** (pin exact versions, at least two weeks old, in `package.json`): `next`, `react`, `react-dom`, `typescript`, `gsap`, `three`, `@hugeicons/react`, `@hugeicons/core-free-icons`, `geist`, `eslint`, `@playwright/test` (dev), `wrangler` (dev, for the Worker).

**Spec:** sections 3, 7, 8, 9.

**Ground rules:**
- No secrets in the site. The demo form uses a form service's public form id from `src/config/site.ts`.
- No client data, no agent API calls.
- Tests and checks before each commit:
  - `npm run lint`, `npm run typecheck` and `npm run build`;
  - the Playwright crawl (task 9).
- Accessibility: semantic HTML, focus states, keyboard access for the menu, accordion and wheel, alt text, and reduced motion (no pins and no WebGL motion; static layouts instead).
- Respect the design tokens from the mockup exactly (WhatsApp palette, Geist, the validated status colours).
- Keep the "Not affiliated with WhatsApp or Meta" line. No WhatsApp or Google logos.

## Task 8: Routing Worker (`worker/`)

- `worker/src/index.ts`:
  - for paths under `/dashboard`, fetch `AGENT_ORIGIN + path`, adding the Cloudflare Access service-token headers from Worker secrets (`CF_ACCESS_CLIENT_ID`, `CF_ACCESS_CLIENT_SECRET`), and stream the response back unchanged (including `Set-Cookie`);
  - on a connection error, or a 502/503/521/522/523/530 from the origin, serve `offline.html` with status 503;
  - pass every other path to the Pages project (`PAGES_ORIGIN`).
- `wrangler.toml` with the route for `waagent.agentsolutionbowl.si/*`. Secrets are set with `wrangler secret put`, never in files.
- **Unit tests** (vitest) of the routing function with fake `fetch`:
  - dashboard paths go to the agent with the headers;
  - other paths go to Pages;
  - origin errors give the offline page;
  - `Set-Cookie` and status pass through;
  - no secret appears in any response.
