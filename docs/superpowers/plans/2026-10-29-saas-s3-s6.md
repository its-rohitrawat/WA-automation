# SaaS S3 to S6 Implementation Plan: the copy tool, customer runtimes, the S5 hookups, and going live

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Copy the founder's SQLite data into Postgres safely and reversibly (S3). Run one isolated runtime per active customer, each with its own keys and caps (S4). Wire the finished S5 screens into the shell (S5 hookups). Hand the owner a tested go-live guide for the Mac (S6).

**Architecture:**
- **The copy tool** runs the whole copy inside one Postgres transaction, then compares counts and a checksum per table before committing. A dry run is the same run ending in `ROLLBACK`.
- **The Supervisor** reads the platform `tenants` table and keeps one `CustomerRuntime` per active customer:
  - each runtime gets a tenant-bound `Db` (`PgTenantDb`, S2), its own data key, its own Anthropic key and its own spend guard;
  - a runtime that crashes is stopped and restarted with backoff, while the others keep running.
- **The dashboard** resolves every request to the session's customer before any data route runs.

**Tech Stack:** Node 24 (TypeScript run directly), `pg` 8.23.x (added in S2.1), better-sqlite3 (read-only in S3), Postgres 17, `@anthropic-ai/sdk` (already a dependency), vitest, `scripts/test-pg.ts` (S2.7).

The options as they were put to the owner:

- **D1: how the platform layer reaches its tables on Postgres.**
  - **Recommended: a third role, `wa_platform`.** It can log in, has no superuser, CREATE or BYPASSRLS rights, owns nothing, and gets `SELECT, INSERT, UPDATE, DELETE` on the six platform tables only, with no grant on any customer table.

- **D2: voice notes for customers.** Transcription today uses the founder's `STT_API_KEY`, which the founder pays for. Recommended: customers get local transcription (`VOICE_STT_PROVIDER=local`) or none in this release. A customer's own STT key comes later.
- **D3: the caps.**
  - Each customer's default daily Claude cap is **US$5**, which they can change in Settings.
  - A **platform-wide daily ceiling of US$100** (`PLATFORM_DAILY_SPEND_CAP_USD`) stops a runaway bug across all runtimes, even though customers pay their own Claude bills.
- **D4: memory per customer.** One Node process cannot measure one customer's memory. The Customers screen shows the real total (`rss`) and each active customer's **share** of what the runtimes added. A start is refused above `PLATFORM_MAX_RSS_MB` (default 4096) as well as above 20 active customers.

## 4. S3: the copy tool

### 4.1 How it works

```
migrate-to-postgres [--apply] [--data-dir data] [--backup-dir <dir>]
  1. preflight: Postgres at PG_LATEST; tracker.db at the latest SQLite version; the agent stopped (no instance lock);
     the founder's customer tables in Postgres empty; with --apply, a backup dir that does not exist yet
  2. with --apply: VACUUM INTO <backup-dir>/tracker.db (and the two session files), then checksum the backups
     against the sources: a backup that does not match stops everything
  3. one transaction on the wa_owner pool:
       BEGIN; SELECT set_config('app.tenant_id', <founder id>, true);
       platform tables, then customer tables in foreign-key order, then wa_auth;
       each table: INSERT ... OVERRIDING SYSTEM VALUE in batches of 500;
       verify: per table, the row count and the checksum, read back inside the same transaction
       dry run (default): ROLLBACK.   --apply and every table OK: setval the identities, COMMIT.
  4. print the report; exit 0 only when every table matched (and, with --apply, the commit succeeded)
```

- **The SQLite files are only read.** They are opened with `readonly: true`, so better-sqlite3 refuses any write. The backup uses `VACUUM INTO`, which reads the source and writes a new file.
- **The checksum** is a SHA-256 over the table's rows, each row a canonical string of its columns in a fixed order, with the lines sorted. It is computed the same way on both sides, so the ordering and collation differences between the engines don't matter.
- **Why `wa_owner`:** keeping the ids needs `OVERRIDING SYSTEM VALUE`, and moving the identity sequences on needs `setval`. Both are owner rights. RLS is FORCED, so the owner is still bound to the founder's id by `set_config`, and a mistake cannot write another customer's rows.
- **Why the dry run is a full run:** everything is inserted and checked, then rolled back. A dry run that passes means `--apply` will pass on the same files.
  - `setval` is not transactional, so the dry run skips it.

```ts
  it('does not depend on row order or on extra columns', () => {

    expect(a.rows).toBe(2);
    expect(a.sha256).toMatch(/^[0-9a-f]{64}$/);
```

```ts
// src/migrate/canonical.ts
import { createHash } from 'node:crypto';

// One canonical string per value, so a table read from SQLite and the same table read from Postgres give the same
// checksum: numbers by their shortest round-trip form (int8 comes back as a number, S2 4.1), text as JSON, bytes as hex.

export function canonicalValue(v: unknown): string {
  if (v === null || v === undefined) return 'N';
  if (typeof v === 'number') return `n${Object.is(v, -0) ? 0 : v}`;
  if (typeof v === 'string') return `s${JSON.stringify(v)}`;
  if (v instanceof Uint8Array) return `b${Buffer.from(v.buffer, v.byteOffset, v.byteLength).toString('hex')}`;
  throw new Error(`cannot compare a ${typeof v === 'object' ? 'object' : typeof v} value`);
}

export interface TableSum {
  rows: number;
  sha256: string;
}

/** The checksum of a table's rows over the given columns: each row a canonical line, the lines sorted, then SHA-256. */
export function tableChecksum(columns: readonly string[], rows: readonly Record<string, unknown>[]): TableSum {
  const lines = rows.map((r) => columns.map((c) => canonicalValue(r[c])).join(String.fromCharCode(31)));
  lines.sort();
  const h = createHash('sha256');
  for (const l of lines) h.update(l).update('\n');
  return { rows: rows.length, sha256: h.digest('hex') };
}
```

```ts
// src/migrate/plan.ts
import type { Sql } from '../store/engine/types.ts';
import { PLATFORM_TABLES } from '../platform/pgSchema.ts';

export interface TablePlan {
  source: 'tracker' | 'session' | 'sender';
  table: string;
  target: string;
  columns: string[];
  /** Values the target needs that the source has no column for (wa_auth's phone and slot). */
  fixed: Record<string, string>;
  platform: boolean;
}

export const SKIPPED: Record<string, string> = {
  schema_version: "SQLite's own migration record; Postgres has pg_schema_version",
  web_sessions: 'sign-in sessions are never copied; the owner signs in again after the switch',
};

export async function copyPlan(tracker: Sql): Promise<TablePlan[]> {
  const names = (await tracker.all<{ name: string }>("SELECT name FROM sqlite_master WHERE type = 'table' AND name NOT LIKE 'sqlite_%' ORDER BY name"))
    .map((t) => t.name).filter((n) => !(n in SKIPPED));
  const deps = new Map<string, string[]>();
  for (const n of names) deps.set(n, (await tracker.all<{ table: string }>(`SELECT "table" FROM pragma_foreign_key_list('${n}')`)).map((f) => f.table).filter((t) => t !== n));
  const order: string[] = [];
  const visit = (n: string, path: string[]) => {
    if (order.includes(n)) return;
    if (path.includes(n)) throw new Error(`foreign keys loop: ${[...path, n].join(' -> ')}`);
    for (const d of deps.get(n) ?? []) visit(d, [...path, n]);
    order.push(n);
  };
  for (const n of names) visit(n, []);
  const out: TablePlan[] = [];
  for (const t of order) {
    const columns = (await tracker.all<{ name: string }>(`SELECT name FROM pragma_table_info('${t}') ORDER BY cid`)).map((c) => c.name);
    out.push({ source: 'tracker', table: t, target: t, columns, fixed: {}, platform: (PLATFORM_TABLES as readonly string[]).includes(t) });
  }
  return out;
}

export const SESSION_PLANS: readonly TablePlan[] = [
  { source: 'session', table: 'auth', target: 'wa_auth', columns: ['k', 'v'], fixed: { phone: 'founder', slot: 'live' }, platform: false },
  { source: 'session', table: 'auth_backup', target: 'wa_auth', columns: ['k', 'v'], fixed: { phone: 'founder', slot: 'backup' }, platform: false },
  { source: 'sender', table: 'auth', target: 'wa_auth', columns: ['k', 'v'], fixed: { phone: 'spare', slot: 'live' }, platform: false },
  { source: 'sender', table: 'auth_backup', target: 'wa_auth', columns: ['k', 'v'], fixed: { phone: 'spare', slot: 'backup' }, platform: false },
];
```

```ts
export interface CopyOptions {
  dataDir: string;
  ownerUrl: string;
  tenantId: string;
  apply: boolean;
  backupDir?: string;
  clock: Clock;

  table: string;
  targetTable: string;
  source: TableSum;
  target: TableSum;

  applied: boolean;
  tables: TableResult[];

const BATCH = 500;

export async function copyToPostgres(o: CopyOptions): Promise<CopyReport> {
  if (o.tamper && process.env.NODE_ENV !== 'test') throw new Error('tamper is for tests only');
  if (o.apply && !o.backupDir) throw new Error('--apply needs --backup-dir <a new folder> for the fresh backup');
  if (o.backupDir && existsSync(o.backupDir)) throw new Error(`The backup folder already exists: ${o.backupDir}. Choose a new one.`);
  // The agent's own instance lock (src/util/lock.ts, as the CLI takes it): held for the whole copy, so the agent cannot
  // start and write to the SQLite files halfway through.
  let lock: { release(): Promise<void> };
  try {
    lock = await acquireLock(o.dataDir);
  } catch (e) {
    if (e instanceof AlreadyRunningError) throw new Error('The agent is running. Stop it first (see docs/GO-LIVE-postgres.md, step 4).');
    throw e;
  }

  const files = { tracker: trackerDbPath(o.dataDir), session: sessionDbPath(o.dataDir), sender: senderSessionDbPath(o.dataDir) };
  const lite = {
    tracker: SqliteDb.open(files.tracker, { readonly: true }),
    session: existsSync(files.session) ? SqliteDb.open(files.session, { readonly: true }) : null,
    sender: existsSync(files.sender) ? SqliteDb.open(files.sender, { readonly: true }) : null,

  try {
    const v = (await lite.tracker.get<{ v: number }>('SELECT max(version) AS v FROM schema_version'))?.v ?? 0;
    if (v !== LATEST_SQLITE) throw new Error(`tracker.db is at v${v}; this version copies v${LATEST_SQLITE}. Start the agent once on SQLite to migrate it.`);
    const pv = (await pool.query('SELECT max(version)::int AS v FROM pg_schema_version')).rows[0]?.v ?? 0;
    if (pv !== PG_LATEST) throw new Error(`Postgres is at P${pv}; run npm run cli -- db-migrate first.`);

    const plans: TablePlan[] = [...(await copyPlan(lite.tracker)), ...SESSION_PLANS.filter((p) => lite[p.source] !== null)];
    // The tables whose id is an identity column keep their ids (OVERRIDING SYSTEM VALUE) and get setval after the copy.
    const identity = new Set<string>((await pool.query("SELECT table_name AS t FROM information_schema.columns WHERE table_schema = 'public' AND column_name = 'id' AND is_identity = 'YES'")).rows.map((r: { t: string }) => r.t));
    let backup: string | null = null;
    if (o.apply) backup = await backupAndVerify(lite, files, o.backupDir!, plans);

    const c = await pool.connect();

    let applied = false;
    try {

      await c.query("SELECT set_config('app.tenant_id', $1, true)", [o.tenantId]);

        if (n > 0) throw new Error(`Postgres already has data in ${p.target}. Nothing was changed.`);

        const rows = await lite[p.source]!.all<Record<string, unknown>>(`SELECT * FROM ${p.table}`);
        await insertRows(c, p, rows, identity.has(p.target));

      if (o.tamper) await c.query(`UPDATE ${o.tamper.table} SET updated_at = 'tampered' WHERE ctid = (SELECT ctid FROM ${o.tamper.table} LIMIT 1)`);
      for (const p of plans) {
        const source = tableChecksum(p.columns, await lite[p.source]!.all<Record<string, unknown>>(`SELECT * FROM ${p.table}`));
        const where = Object.keys(p.fixed).map((k, i) => `${k} = $${i + 1}`).join(' AND ');
        const back = (await c.query(`SELECT ${p.columns.join(', ')} FROM ${p.target}${where ? ` WHERE ${where}` : ''}`, Object.values(p.fixed))).rows;
        const target = tableChecksum(p.columns, back);
        tables.push({ table: `${p.source}:${p.table}`, targetTable: p.target, source, target, match: source.rows === target.rows && source.sha256 === target.sha256 });
      }
      const ok = tables.every((t) => t.match);
      if (o.apply && ok) {
        for (const p of plans.filter((x) => identity.has(x.target))) {
          await c.query(`SELECT setval(pg_get_serial_sequence($1, 'id'), GREATEST((SELECT max(id) FROM ${p.target}), 1))`, [p.target]);

        await c.query('COMMIT');
        applied = true;
      } else {
        await c.query('ROLLBACK');
      }
      return { ok, applied, tables, backup };
    } catch (e) {

      c.release();

    await pool.end();
    await lite.tracker.close();
    await lite.session?.close();
    await lite.sender?.close();
    await lock.release();
  }
}
```

```ts
async function insertRows(c: pg.PoolClient, p: TablePlan, rows: Record<string, unknown>[], keepIds: boolean): Promise<void> {
  const cols = [...p.columns, ...Object.keys(p.fixed)];
  const identity = keepIds ? ' OVERRIDING SYSTEM VALUE' : '';
  for (let i = 0; i < rows.length; i += BATCH) {
    const chunk = rows.slice(i, i + BATCH);
    const values: unknown[] = [];
    const tuples = chunk.map((r) => `(${cols.map((col) => {
      values.push(col in p.fixed ? p.fixed[col] : r[col]);
      return `$${values.length}`;
    }).join(', ')})`);
    const upsert = p.target === 'tenants' ? ' ON CONFLICT (id) DO UPDATE SET name = excluded.name, kind = excluded.kind, status = excluded.status, created_at = excluded.created_at, updated_at = excluded.updated_at, signed_up_at = excluded.signed_up_at, last_activity_at = excluded.last_activity_at' : '';
    await c.query(`INSERT INTO ${p.target} (${cols.join(', ')})${identity} VALUES ${tuples.join(', ')}${upsert}`, values);
  }
}

/** VACUUM INTO each source, then checks that each backup holds exactly what its source holds. */
async function backupAndVerify(lite: Record<'tracker' | 'session' | 'sender', SqliteDb | null>, files: Record<'tracker' | 'session' | 'sender', string>, dir: string, plans: TablePlan[]): Promise<string> {
  mkdirSync(dir, { recursive: true, mode: 0o700 });
  for (const k of ['tracker', 'session', 'sender'] as const) {
    if (!lite[k]) continue;
    const to = join(dir, files[k].split(/[\\/]/).pop()!);
    await lite[k]!.run('VACUUM INTO ?', [to]);
    const copy = SqliteDb.open(to, { readonly: true });
    try {
      for (const p of plans.filter((x) => x.source === k)) {
        const a = tableChecksum(p.columns, await lite[k]!.all(`SELECT * FROM ${p.table}`));
        const b = tableChecksum(p.columns, await copy.all(`SELECT * FROM ${p.table}`));
        if (a.sha256 !== b.sha256) throw new Error(`The backup of ${p.table} does not match its source. Nothing was copied.`);
      }
    } finally {
      await copy.close();
    }
  }
  return dir;
}
```

```ts
// src/platform/tenantKeys.ts
import { randomBytes } from 'node:crypto';
import { decrypt, encrypt } from '../crypto/envelope.ts';
import { deriveSubkey } from '../crypto/keyProvider.ts';
import type { Sql } from '../store/engine/types.ts';
import type { Clock } from '../util/clock.ts';
import { FOUNDER_TENANT_ID } from './store.ts';

// Each customer's data key (design 7): 32 random bytes, stored only wrapped (AES-256-GCM) by a key derived from the
// Mac's master key, with the customer id as the AAD. The founder's data key is the master key itself: everything the
// agent stored before the SaaS (WhatsApp auth, Google tokens, media references) was encrypted with it.

const WRAP_INFO = 'wa-agent tenant data keys v1';

export class TenantKeys {
  readonly #db: Sql;
  readonly #wrap: Buffer;
  readonly #master: Buffer;
  readonly #clock: Clock;
  readonly #cache = new Map<string, Buffer>();

  constructor(o: { db: Sql; master: Buffer; clock: Clock }) {
    this.#db = o.db;
    this.#master = Buffer.from(o.master);
    this.#wrap = deriveSubkey(o.master, WRAP_INFO);
    this.#clock = o.clock;
  }

  /** The customer's data key, made on first use. */
  async dataKey(tenantId: string): Promise<Buffer> {
    if (tenantId === FOUNDER_TENANT_ID) return Buffer.from(this.#master);
    const hit = this.#cache.get(tenantId);
    if (hit) return Buffer.from(hit);
    const aad = Buffer.from(`tenant:${tenantId}`);
    const row = await this.#db.get<{ wrapped: Buffer }>('SELECT wrapped FROM tenant_keys WHERE tenant_id = ?', [tenantId]);
    let key: Buffer;
    if (row) {
      try {
        key = decrypt(this.#wrap, Buffer.from(row.wrapped), aad);
      } catch {
        throw new Error("This customer's data key cannot be opened with this Mac's master key.");
      }
    } else {
      key = randomBytes(32);
      await this.#db.run('INSERT INTO tenant_keys (tenant_id, wrapped, created_at) VALUES (?, ?, ?) ON CONFLICT (tenant_id) DO NOTHING', [tenantId, encrypt(this.#wrap, key, aad), this.#clock.now().toISOString()]);
      // Another start may have won the race: read back what is stored.
      const back = await this.#db.get<{ wrapped: Buffer }>('SELECT wrapped FROM tenant_keys WHERE tenant_id = ?', [tenantId]);
      key = decrypt(this.#wrap, Buffer.from(back!.wrapped), aad);
    }
    this.#cache.set(tenantId, key);
    return Buffer.from(key);
  }
}
```

**Files:**

**The rules:**
1. On `reconcile()`, every `active` customer has a runtime; every `paused` or `removed` one has none. `onboarding` customers get a **setup runtime**, built with `{ setupOnly: true }`: WhatsApp linking and Google connect only, no AI work and no batches.
2. A start beyond `maxActive` running runtimes, or with `rss` above `maxRssMb`, is refused. The customer shows `refused: limit` or `refused: memory` and is not retried until the next reconcile, when room exists.
3. A start that throws, or a runtime that reports a crash, is stopped, then restarted after `backoff(n)`:
   - 1 s, 2 s, 4 s and so on, up to 5 minutes;
   - `n` resets after 10 minutes of running;
   - after 5 crashes in an hour, the customer shows `failing` on the Customers screen and keeps the 5-minute pace.
4. Crashes are audited (`runtime.crashed`, with the error's `name` and `code` only, never its message, which can hold customer data).
5. `reconcile()` runs at start, after every pause, resume or activation (the platform routes call `supervisor.poke()`), and every 60 s.
6. `stopAll()` stops every runtime in parallel, each with a 10 s limit.

```ts
/** The wait before the nth restart (n from 1): 1 s doubling, at most 5 minutes. */
export function backoffMs(n: number): number {
  return Math.min(300_000, 1_000 * 2 ** Math.max(0, n - 1));
```

```ts
import { AsyncLocalStorage } from 'node:async_hooks';

/** The customer whose runtime is running this code: set when a runtime starts, inherited by its timers and promises. */
export const tenantContext = new AsyncLocalStorage<string>();

export type CrashReport = (tenantId: string, e: unknown) => void;

/**
 * Wraps a runtime's entry points (socket events, timers, ticks), so a throw there stops and restarts that customer
 * instead of the process. Works for both sync and async functions.
 */
export function guarded(tenantId: string, report: CrashReport) {
  return <A extends unknown[], R>(fn: (...a: A) => R) => (...a: A): R | undefined => {
    try {
      const r = fn(...a);
      if (r instanceof Promise) return r.catch((e: unknown) => void report(tenantId, e)) as R;
      return r;
    } catch (e) {
      report(tenantId, e);
      return undefined;
    }
  };
}
```

```ts
// src/runtime/supervisor.ts (the core; the audit and logging lines follow the platform style)
import type { Sql } from '../store/engine/types.ts';
import type { Clock } from '../util/clock.ts';
import type { Logger } from '../util/logger.ts';
import { platformAudit } from '../platform/store.ts';
import { backoffMs } from './backoff.ts';
import { tenantContext } from './context.ts';

export interface RuntimeHandle {
  stop(): Promise<void>;
}
export interface RuntimeFactory {
  start(t: { id: string; founder: boolean; setupOnly: boolean }): Promise<RuntimeHandle>;
}
export type RuntimeState = 'starting' | 'running' | 'backoff' | 'failing' | 'stopped' | 'refused:limit' | 'refused:memory' | 'refused:postgres';

interface Slot {
  state: RuntimeState;
  handle: RuntimeHandle | null;
  setupOnly: boolean;
  crashes: number[];
  startedAt: number;
  timer: ReturnType<typeof setTimeout> | null;
}

export interface SupervisorDeps {
  db: Sql;
  clock: Clock;
  log: Logger;
  factory: RuntimeFactory;
  maxActive: number;
  maxRssMb: number;
  rssMb: () => number;
  engine: 'sqlite' | 'postgres';
  setTimer?: (fn: () => void, ms: number) => ReturnType<typeof setTimeout>;
}

export class Supervisor {
  readonly #d: SupervisorDeps;
  readonly #slots = new Map<string, Slot>();
  #running: Promise<void> = Promise.resolve();

  constructor(d: SupervisorDeps) {
    this.#d = d;
  }

  state(id: string): RuntimeState {
    return this.#slots.get(id)?.state ?? 'stopped';
  }

  /** Brings the runtimes in line with the tenants table; calls are queued, never run at the same time. */
  reconcile(): Promise<void> {
    this.#running = this.#running.then(() => this.#reconcile()).catch((e) => this.#d.log.error({ err: e }, 'supervisor reconcile failed'));
    return this.#running;
  }

  async #reconcile(): Promise<void> {
    const rows = await this.#d.db.all<{ id: string; kind: string; status: string }>("SELECT id, kind, status FROM tenants WHERE status <> 'removed' ORDER BY kind = 'founder' DESC, created_at");
    const want = new Map(rows.filter((r) => r.status === 'active' || r.status === 'onboarding').map((r) => [r.id, r]));
    for (const [id, slot] of this.#slots) if (!want.has(id) && (slot.handle || slot.timer)) await this.#stop(id, 'stopped');
    let running = [...this.#slots.values()].filter((s) => s.handle && !s.setupOnly).length;
    for (const r of want.values()) {
      const founder = r.kind === 'founder';
      const setupOnly = r.status === 'onboarding';
      const slot = this.#slots.get(r.id);
      // Running, starting, or waiting out a backoff (its timer calls reconcile again): leave it. A refused or stopped
      // slot has neither, so it is tried again here.
      if (slot && (slot.handle !== null || slot.timer !== null || slot.state === 'starting') && slot.setupOnly === setupOnly) continue;
      if (slot?.handle) await this.#stop(r.id, 'stopped'); // onboarding became active: restart as a full runtime
      if (!founder && this.#d.engine === 'sqlite') {
        this.#set(r.id, 'refused:postgres', setupOnly);
        continue;
      }
      if (!founder && !setupOnly && running >= this.#d.maxActive) {
        this.#set(r.id, 'refused:limit', setupOnly);
        continue;
      }
      if (!founder && this.#d.rssMb() > this.#d.maxRssMb) {
        this.#set(r.id, 'refused:memory', setupOnly);
        continue;
      }
      if (await this.#start(r.id, founder, setupOnly)) running += setupOnly ? 0 : 1;
    }
  }

  #set(id: string, state: RuntimeState, setupOnly: boolean): Slot {
    const slot = this.#slots.get(id) ?? { state, handle: null, setupOnly, crashes: [], startedAt: 0, timer: null };
    slot.state = state;
    slot.setupOnly = setupOnly;
    this.#slots.set(id, slot);
    return slot;
  }

  async #start(id: string, founder: boolean, setupOnly: boolean): Promise<boolean> {
    const slot = this.#set(id, 'starting', setupOnly);
    try {
      slot.handle = await tenantContext.run(id, () => this.#d.factory.start({ id, founder, setupOnly }));
      slot.state = 'running';
      slot.startedAt = this.#d.clock.now().getTime();
      return true;
    } catch (e) {
      await this.#crash(id, e);
      return false;
    }
  }

  async #stop(id: string, then: RuntimeState): Promise<void> {
    const slot = this.#slots.get(id);
    if (!slot) return;
    if (slot.timer) clearTimeout(slot.timer);
    slot.timer = null;
    const h = slot.handle;
    slot.handle = null;
    slot.state = then;
    if (h) await Promise.race([h.stop(), new Promise((r) => setTimeout(r, 10_000).unref())]).catch((e) => this.#d.log.warn({ tenant: id, err: { name: (e as Error).name } }, 'runtime stop failed'));
  }

  /** A runtime reports a crash (guarded() or the process handler). */
  crashed(id: string, e: unknown): void {
    void this.#crash(id, e);
  }

  async #crash(id: string, e: unknown): Promise<void> {
    const slot = this.#slots.get(id);
    if (!slot || slot.state === 'stopped') return;
    const now = this.#d.clock.now().getTime();
    if (slot.state === 'running' && now - slot.startedAt >= 600_000) slot.crashes = [];
    slot.crashes = [...slot.crashes.filter((t) => now - t < 3_600_000), now];
    await this.#stop(id, slot.crashes.length >= 5 ? 'failing' : 'backoff');
    slot.state = slot.crashes.length >= 5 ? 'failing' : 'backoff';
    const err = e as { name?: unknown; code?: unknown };
    await platformAudit(this.#d.db, {
      at: new Date(now).toISOString(), actor: 'supervisor', event: 'runtime.crashed', tenantId: id,
      detail: `${typeof err?.name === 'string' ? err.name : 'Error'} ${typeof err?.code === 'string' ? err.code : ''}`.trim().slice(0, 100), requestId: null,
    }).catch(() => undefined);
    const set = this.#d.setTimer ?? ((fn, ms) => setTimeout(fn, ms).unref());
    slot.timer = set(() => {
      slot.timer = null;
      void this.reconcile();
    }, backoffMs(slot.crashes.length));
  }

  /** Every runtime, in parallel, each within 10 s. */
  async stopAll(): Promise<void> {
    await Promise.all([...this.#slots.keys()].map((id) => this.#stop(id, 'stopped')));
  }
}
```
